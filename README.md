# Unraid templates by Aegisnir

Unraid Community Applications templates.  This repo holds template definitions only: each app's container image or plugin, and its source, live in the app's own repository.

## Apps

| App | Upstream | Packaged for Unraid by | Source |
|---|---|---|---|
| SD-WebUI-Forge-Neo-Unraid | [Forge Neo](https://github.com/Haoming02/sd-webui-forge-classic/tree/neo) by Haoming02 | Aegisnir | [aegisnir/SD-WebUI-Forge-Neo-Unraid](https://github.com/aegisnir/SD-WebUI-Forge-Neo-Unraid) |
| Aether Glass (plugin) | Original work | Aegisnir | [aegisnir/Aether-Glass-Unraid-Theme](https://github.com/aegisnir/Aether-Glass-Unraid-Theme) |
